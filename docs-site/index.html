QUADQR EXPERIMENTAL

Build with QuadQR in the browser or Node.js.

Generate, render, scan, compress, sign, encrypt, diagnose, and stress-test QuadQR payloads with one shared JavaScript codec, including the optional experimental High Density Mode implemented with Triangle16 split cells. Use the npm package, a browser bundler, Node.js, the CLI, or a plain script tag from a CDN.

QUICK START

Encode text and decode the matrix

import { encodeText, decodeMatrix } from "quadqr-js";

const code = encodeText("Hello QuadQR", {
  ecc: "M",
  highDensity: true // optional; disabled by default
});
const result = decodeMatrix(code.matrix);

console.log(result.text); // Hello QuadQR

When no version is supplied, QuadQR chooses the smallest version that can hold the payload. High Density Mode is disabled by default. When enabled, its Triangle16 layout splits each payload module on a fixed / diagonal, giving 16 RGBW pair states and 4 raw bits per body cell. The protected header remains solid-color for reliability.

BROWSER

Render, scan image files, and use the camera

import {
  encodeText,
  renderToCanvas,
  renderToSVG,
  scanFile,
  startCameraScanner
} from "quadqr-js/browser";

const code = encodeText("Hello from the browser", { ecc: "M" });
renderToCanvas(code, document.querySelector("#qr"), {
  quietZone: 4
});

const svg = renderToSVG(code, {
  imageSize: 720,
  quietZone: 4
});

// Image upload
const fileInput = document.querySelector("#image");
const imageResult = await scanFile(fileInput.files[0]);
console.log(imageResult.text);

// Live camera
let scanner;
scanner = await startCameraScanner(document.querySelector("#video"), {
  cameraFinderRecoveryEvery: 2,
  cameraHighResolutionMaxDimension: 1600,
  onResult(result) {
    console.log(result);
    scanner.stop();
  },
  onDiagnostic(event) {
    // Finder positions + locator/recovery method for overlays/logs.
    console.log(event.method, event.finderMethod, event.finderCount, event.geometry?.version);
  }
});

Camera access requires HTTPS or localhost. The fast locator pass uses max(R,G,B) so colored data cells are less likely to look like structural black. Dense misses with at least two finders can retry the visible camera ROI at higher resolution before stronger recovery. Perspective-tolerant finder recovery and distributed alignment markers then help refine geometry without changing the QuadQR format or reducing capacity. The optional diagnostics callback exposes those existing locator passes without adding another detection loop. Secure scans return a locked result first and can be decrypted with decryptDecoded().

NODE.JS

Generate PNG/SVG files and scan images on the server

import { encodeText } from "quadqr-js";
import { savePNG, saveSVG, scanFile } from "quadqr-js/node";

const code = encodeText("Generated on Node.js");
await savePNG(code, "quadqr.png", {
  imageSize: 720,
  quietZone: 4
});

await saveSVG(code, "quadqr.svg", {
  imageSize: 720,
  quietZone: 4
});

const result = await scanFile("quadqr.png");
console.log(result.text);

PNG support is built in and does not require a native image dependency. JPEG, WebP, and AVIF input can use sharp when it is installed by the consuming project.

SCANNING

One scanner pipeline across browser images, camera frames, and Node.js

Pixels→Geometry→Color calibration→Spectrum ECC→Payload
RGBA pixelsscanImageData()

Runtime-neutral scanning when your app already has decoded pixels.

Browser filesscanFile()

Scan uploaded images directly from a browser File or Blob.

Live camerastartCameraScanner()

Uses RGB-value finder detection on the fast pass. Dense misses with two or more finders can retry the visible ROI at up to 1600 px, followed by perspective-tolerant finder recovery, distributed-alignment geometry refinement, and same-frame Photoshop-style Auto Color recovery inside guide-centered crops when needed. The normal path stays fast; these recovery paths and multi-frame confidence fusion run only after a miss. Frame evidence keeps per-cell confidence and alternate states for Spectrum ECC 2.0.

Image and camera scanning automatically detect normal RGBW symbols and experimental High Density Mode symbols. High Density Mode uses Triangle16 multi-point region sampling. Three protected anchors per triangle are robustly combined away from the diagonal boundary, and unstable regions lower confidence instead of becoming hard errors. Advanced calibration can also fit an affine cross-channel correction from the known black/white/R/G/B references. Image and camera scanning use the same secure-aware decoding behavior. An encrypted symbol is detected normally, but plaintext is not exposed until the correct credential is supplied.

SECURE PAYLOAD V1

Optional authenticated encryption for protected data

Secure Payload is opt-in. Normal QuadQR codes remain unencrypted and require no password or key.

Password mode

Designed for human-entered secrets. PBKDF2-HMAC-SHA-256 derives a 256-bit key and AES-256-GCM protects confidentiality and integrity.

Raw 256-bit key mode

Designed for applications that already manage cryptographic keys, such as provisioning systems, ticket scanners, and device workflows.

import {
  encodeSecureText,
  decodeMatrix,
  decryptDecoded
} from "quadqr-js";

const code = await encodeSecureText("Private payload", {
  security: {
    mode: "password",
    password: "correct horse battery staple"
  }
});

const locked = decodeMatrix(code.matrix);
const result = await decryptDecoded(locked, {
  password: "correct horse battery staple"
});

console.log(result.text);

For application-managed keys, set mode: "raw-key" and provide an exact 32-byte key. The key itself is never stored in the QuadQR symbol.

PAYLOAD TOOLS

Normal payloads with optional compression and signatures

QuadQR does not require a semantic payload type. Encode normal text or bytes, then enable compression or Ed25519 signing only when your application needs them. Any transport metadata is handled internally.

const compressed = QuadQR.encodeText("repeat repeat repeat repeat", {
  compression: "auto",
  ecc: "Q"
});

const keys = await QuadQR.generateSigningKeyPair();
const signed = await QuadQR.encodeSignedText("ticket", {
  compression: "auto",
  privateKey: keys.privateKey,
  keyId: keys.keyId
});

const checked = await QuadQR.verifyDecodedSignature(
  QuadQR.decodeMatrix(signed.matrix),
  { publicKey: keys.publicKey }
);
console.log(checked.signatureVerified, checked.signatureTrusted);

compression: "auto" compares balanced Brotli, portable DEFLATE, and legacy LZ, and adds no compression envelope when the final stored result would not save space. The private key signs, while the trusted public key stays outside the QuadQR by default. The compact key ID helps a scanner select the correct trusted verification key.

RENDERING

Use styles, logos, quiet zones, and vector export

renderToCanvas(code, document.querySelector("#qr"), {
  imageSize: 720,
  quietZone: 6,
  style: "classic", // classic | depth | soft | inset
  logo: {
    source: loadedLogoImage,
    size: "auto",
    clearBackground: true
  }
});

const svg = renderToSVG(code, {
  imageSize: 720,
  quietZone: 6,
  mode: "print"
});

Use mode: "print" for a minimum 4-module quiet zone, darker print-safe primaries, and Classic solid modules. size: "auto" estimates a conservative ECC-aware logo size. getPrintGuidance() reports physical module sizing when you know the target millimeters and DPI.

SCANNER DIAGNOSTICS

See where a scan succeeds or fails

const result = QuadQR.scanImageData(imageData, { debug: true });
console.log(result.confidence);
console.log(result.geometryConfidence);
console.log(result.calibrationConfidence);
console.log(result.eccUtilization);
console.log(result.diagnostics.stages);

Debug mode can expose finder/geometry candidates, color-normalization method, sampled matrix and confidence matrix, ECC correction usage, and the stage that failed. debugScanImageData() is a non-throwing helper for diagnostic tools.

RELIABILITY LAB

Deterministic camera and 3D perspective testing

const report = QuadQR.assessScanability(code, {
  imageSize: 480,
  logo: { source: logoImageData, size: "auto" }
});

console.log(report.score, report.rating);

const lab = QuadQR.runReliabilityLab(imageData, {
  version: code.version,
  crc32: code.crc32
}, { suite: "full" });

const sweep = QuadQR.runPerspectiveSweep(imageData, {
  version: code.version,
  crc32: code.crc32
}, { axis: "yaw", angles: [0, 15, 25, 35, 45, 55] });

The Reliability Lab adds motion blur, glare, sensor noise, color casts, 3D X/Y tilt, Z rotation, combined projective angles, category scores and angle sweeps. The demo has a dedicated Reliability Lab tab with a live perspective playground. Synthetic scores are regression aids, not a replacement for real camera and printer testing.

CDN

Use QuadQR from a script tag with no build step

<canvas id="qr"></canvas>
<script src="https://cdn.jsdelivr.net/npm/quadqr-js@1.1.0/dist/quadqr.min.js"></script>
<script>
  const code = QuadQR.encodeText("Hello from a script tag");
  QuadQR.renderToCanvas(code, document.querySelector("#qr"));
</script>

The same global build is available through unpkg. Pin an exact package version for production sites.

CLI

Encode and decode QuadQR from the terminal

# Normal QuadQR
npx quadqr-js encode "Hello QuadQR" -o hello.png
npx quadqr-js decode hello.png

# Automatic compression
npx quadqr-js encode "repeat repeat repeat" --compression auto -o compressed.svg

# Print-safe output
npx quadqr-js encode "Print me" --print -o print.svg

# Ed25519 signed payload
npx quadqr-js signkeygen -o signing-key.json
npx quadqr-js encode "Verified ticket" --sign-key signing-key.json -o signed.png
npx quadqr-js decode signed.png --verify-key signing-key.json

# Password-protected QuadQR
npx quadqr-js encode "Private data" --password "my-password" -o secure.png
npx quadqr-js decode secure.png --password "my-password"

The CLI also supports --debug scanner diagnostics, --key <64-hex-key>, and signed + encrypted composition. See the CLI guide for all options.

OPTIONAL WASM

Enable the bundled accelerator when you want it

import { initWasm } from "quadqr-js";

await initWasm();

The JavaScript codec works without WASM. In 1.x the optional prebuilt module accelerates CRC-32 while keeping the same public API and wire format.
