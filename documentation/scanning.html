Scanning & Camera

QuadQR uses one scanning pipeline across browser image uploads, live camera frames, and runtime-neutral RGBA pixels. The scanner combines geometry recovery, color calibration, confidence-aware decoding, and Spectrum ECC.

Scanner pipeline

Pixels→Finder recovery→Perspective geometry→Color calibration→Spectrum ECC→Payload

Scan an uploaded browser image

JAVASCRIPT
import { scanFile } from "quadqr-js/browser";

const result = await scanFile(fileInput.files[0]);
console.log(result.text);

Live camera scanning

JAVASCRIPT
import { startCameraScanner } from "quadqr-js/browser";

const scanner = await startCameraScanner(video, {
  cameraFinderRecoveryEvery: 2,
  cameraHighResolutionMaxDimension: 1600,
  onResult(result) {
    console.log(result);
    scanner.stop();
  },
  onDiagnostic(event) {
    console.log(
      event.method,
      event.finderMethod,
      event.finderCount,
      event.geometry?.version
    );
  }
});
Camera requirement

Browser camera access requires HTTPS or localhost.

Perspective and dense-symbol recovery

The fast locator pass uses the maximum RGB channel so colored payload cells are less likely to look like structural black. When a dense frame misses, the scanner can retry the visible region at higher resolution, use perspective-tolerant finder recovery, and refine geometry with distributed alignment markers.

Recovery can also apply same-frame color normalization inside guide-centered regions when lighting or white balance shifts the RGBW palette. These heavier paths run after a miss so the normal camera path stays responsive.

Multi-frame confidence fusion

Camera scanning can combine evidence from multiple frames instead of treating each frame as an isolated hard decision. Per-cell confidence and alternate color states are retained so Spectrum ECC 2.0 can use soft evidence when a cell is unstable.

High Density Mode scanning

High Density Mode is detected automatically. Triangle16 cells are sampled with multiple protected points per triangle away from the diagonal boundary. Unstable regions lower confidence instead of immediately becoming hard symbol errors.

Diagnostics

JAVASCRIPT
const result = QuadQR.scanImageData(imageData, { debug: true });

console.log(result.confidence);
console.log(result.geometryConfidence);
console.log(result.calibrationConfidence);
console.log(result.eccUtilization);
console.log(result.diagnostics.stages);

Debug mode can expose finder and geometry candidates, color normalization, sampled matrices, cell confidence, ECC correction usage, and the stage that failed. debugScanImageData() is the non-throwing helper intended for diagnostic interfaces.

Secure scans

Encrypted symbols are located and decoded normally, but plaintext is not exposed until credentials are supplied to decryptDecoded(). The scanner does not need a separate secure mode.

Test scanner robustness

Use the Reliability Lab for deterministic distortion suites and pitch, yaw, and Z-rotation sweeps before relying on a chosen physical size or camera setup.
