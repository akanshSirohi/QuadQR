Your first QuadQR.

JAVASCRIPT
import { encodeText, decodeMatrix } from "quadqr-js";

const code = encodeText("Hello QuadQR", { ecc: "M" });
const result = decodeMatrix(code.matrix);

console.log(result.text); // Hello QuadQR
Automatic sizing

If you do not supply a version, QuadQR chooses the smallest version that fits the encoded payload and selected protection settings.

FORMAT

RGBW by default, Triangle16 when requested.

Normal RGBW

Four color states represent 2 raw bits per payload data cell. This is the default mode.

Read format reference →

High Density

Each body cell is split diagonally into two RGBW triangles for 16 states and 4 raw bits.

Read High Density guide →
Custom symbology

QuadQR is not an ISO QR Code. Standard QR scanner apps do not decode QuadQR symbols.
