Configuration Reference

Every supported public option in QuadQR 1.5.1, with accepted values, defaults, behavior, and the context in which it matters. This page is generated from the runtime implementation rather than from UI labels.

Public versus internal settings

Options beginning with an underscore, such as _observationCollector, are private scanner plumbing and are intentionally not part of the supported API. Everything below is intended for application use or is accepted by a documented public function.

Encoding, version and ECC#

OptionType / accepted valuesDefaultWhat it does
ecc"L" | "M" | "Q" | "H""M"Selects the Spectrum ECC profile. Higher letters add more Reed-Solomon parity and reduce payload capacity. The letters are QuadQR profiles and are not recovery-equivalent to ISO QR ECC letters.
version"auto" or integer 1..40"auto"Fixes the matrix version or lets QuadQR choose the smallest version that fits the final encoded payload.
minVersioninteger 1..401Lower bound used by automatic version selection and scanner searches.
maxVersioninteger 1..4040Upper bound used by automatic version selection and scanner searches. Must be greater than or equal to minVersion.
highDensitybooleanfalseConvenience switch for experimental Triangle16. true is equivalent to cellEncoding: "triangle16".
cellEncoding"rgbw" | "triangle16""rgbw"Selects the physical data-cell encoding. RGBW carries 2 raw bits per body cell; Triangle16 carries 4 raw bits by splitting each body module into two RGBW triangles.
formatVersioninteger6 for new encodingCompatibility guard for encoding. New symbols use Format v6. The scanner retains backward decoding for legacy Format v5 symbols.

Terminology#

TermMeaning
moduleOne square position in the QuadQR matrix. Structural and RGBW data cells occupy modules; Triangle16 body modules contain two triangular color regions.
cellThe logical value stored/rendered at a module position. RGBW data cells are values 0..3; Triangle16 body cells pack two RGBW colors into states 0..15.
finder patternLarge black/white locator structure used to find the symbol and establish orientation.
alignment patternDistributed smaller structural marker used to refine perspective geometry, especially on larger/dense symbols.
quiet zoneBlank margin around the matrix, measured in modules.
homographyProjective transform mapping an angled camera view back to ideal matrix coordinates.
calibrationUsing known structural/color reference cells inside QuadQR to learn how black, white, red, green, and blue appear under current lighting/camera conditions.
erasureA Reed-Solomon symbol the scanner explicitly marks as unreliable. Known erasure positions can be easier to recover than unknown errors.
soft decodingA bounded second-stage decode that substitutes the scanner’s second-best color hypothesis for a few low-confidence cells when normal ECC still fails.
Spectrum ECC 2.0QuadQR’s confidence-aware decoding pipeline around GF(256) Reed-Solomon, including spectral/spatial interleaving, erasures, and bounded soft alternatives.
QuadQR Auto ColorPer-channel level correction used primarily to recover finder visibility and strong warm/cool color casts.
Auto Tone / Contrast / ColorBroader recovery transform that neutralizes highlights, expands per-channel tone/contrast, and applies a conservative saturation boost.
multi-frame fusionCombines several compatible camera observations with confidence and recency weighting before another decode attempt.
recovery cadenceAn *Every camera option controlling how many missed scan cycles occur between expensive recovery attempts.
Triangle16Experimental High Density physical layout with a fixed diagonal split and two independently colored RGBW triangle regions per body module.
utilizationHow much of the available data-cell area is occupied by meaningful protected payload/header cells rather than deterministic padding.
